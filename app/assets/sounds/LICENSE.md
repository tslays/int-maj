# Sounds

`dice-1.mp3` to `dice-4.mp3` are four recorded throws of two dice, from one
**freesound.org** sound, released
under **Creative Commons Zero (CC0 1.0)**,
<http://creativecommons.org/publicdomain/zero/1.0/>: free for personal and
commercial use, no credit required. The project owner supplied it and stated
the CC0 licence. The sound's title and author are not recorded here; add them
to this file when known.

Each throw was cut out of the file (about 0.6 s each), converted to mono MP3
(96 kbit/s, so every phone can decode it) and set to a peak of -3 dB. Nothing else was
changed.

Every other sound in the game is synthesised in `src/sound.js`.
